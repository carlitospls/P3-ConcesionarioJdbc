# P3 · Cómo abrirlo (léelo, que en P2 hubo lío con Git)

1. Descomprime el zip. Te queda una carpeta `P3-ConcesionarioJdbc` con `pom.xml` **directamente dentro**.
2. IntelliJ → **File → Open** → selecciona **esa carpeta** (la que tiene el `pom.xml`), no la de arriba.
3. Run → abre `localhost:8080` → comprueba que se ven Coches y Marcas **antes** de tocar nada.
4. **Git → GitHub → Share Project on GitHub**, nombre `P3-ConcesionarioJdbc`. Eso crea el repo con la base.
5. Pon el cronómetro y abre `ENUNCIADO.md` (está aquí, al lado del `pom.xml`).
6. Al acabar: **Ctrl+K** → marca los archivos → **Commit and Push**.
